## 🎯 Track Overview & Objectives
This repository contains all daily work, project code, reports, and evidence for the **Data Analytics Track**. The primary objective is to solve core business problems through data-driven approaches, designed around the key business question progression:  
*What happened? → Why did it happen? → What will happen next? → What should we do about it?*

### Key Technical Competencies:
* **Metrics & Analytics:** Business KPIs, metric trees, cohort retention analysis, RFM customer segmentation, and $A/B$ testing.
* **SQL & Data Querying:** Aggregations, multi-table joins, `CASE` logic, Common Table Expressions (CTEs), and window functions (`LAG`, `RANK`, `ROW_NUMBER`).
* **Python for Data Science:** `pandas`, `numpy`, `scikit-learn`, statistical testing (`scipy`), regression, classification, clustering, and time-series forecasting.
* **Business Intelligence & Visualization:** Power BI (Data modeling, DAX time-intelligence), Tableau Public, and interactive dashboards.
