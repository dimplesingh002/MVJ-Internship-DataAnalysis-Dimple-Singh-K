## 1. Selected Tools Explored (Section 9 Review)
* **Microsoft Fabric (MS-FAB):** An all-in-one analytics solution for enterprises that covers everything from data movement to data science, real-time analytics, and business intelligence. It integrates Data Factory, Azure Synapse, and Power BI into a single unified platform.
* **Microsoft Copilot (MS-COP):** An AI-powered productivity tool embedded across Microsoft 365 apps and development environments to assist with coding, debugging, summarizing text, and automating repetitive tasks.

## 2. 30-Minute Hands-On Trial Reflection
* **Tool Tested:** Microsoft Copilot / AI Coding Assistants.
* **What I Did:** Tested prompt-based debugging and SQL query generation for retail datasets, comparing generated outputs against manual Pandas aggregations.
* **Key Takeaway:** AI assistants significantly accelerate the initial boilerplate code generation phase, but verifying data types, aggregation logic, and edge cases manually remains crucial for data integrity.
