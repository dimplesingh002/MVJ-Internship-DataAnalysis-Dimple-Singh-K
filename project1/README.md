# Project 1: Online Retail KPI Analysis

## 1. Business Question
What are the core revenue drivers, top-performing products, and monthly growth trends for the online retail dataset, and how can the business improve customer retention and sales?

## 2. Data Source
* **Dataset:** Online Retail II (UCI Machine Learning Repository)[cite: 8]
* **Link:** https://archive.ics.uci.edu/dataset/502/online+retail+ii[cite: 10]
* **Format:** SQLite Database (`online_retail.db`) queried via SQL and analyzed in Excel.

## 3. Key Findings (Metrics)
* **Total Revenue:** 19287250.568
* **Average Order Value (AOV):** 359.648888043559
* **Top Product:** REGENCY CAKESTAND 3 TIER

## 4. Business Recommendations
1. Focus marketing efforts on top-performing products identified in the SQL ranking queries to maximize conversion.
2. Implement targeted retention campaigns for repeat customers who drive consistent high-value orders.
3. Address seasonal dips in monthly revenue by introducing promotional discount events during slower months.
4. Optimize inventory stocking for high-demand regions and top revenue-generating countries.
5. Streamline checkout and return processes to mitigate revenue leakage caused by transaction cancellations.
